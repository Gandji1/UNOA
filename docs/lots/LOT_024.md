# Lot 024 — Formations courtes

Relecture du 25 novembre 2026 : TDR module SHORT (REQ-SHORT-001 à 010 ; processus catalogue → inscription →
apprentissage → évaluation → attestation ; exceptions : certificat présenté comme diplôme d'État, parcours
incomplet), lots 008 (contenus validés), 022 (tarifs), 023 (registre des documents).

## Fiche

- Entités : formation courte (durée libre, compétences, seuil de réussite par module, document délivré),
  modules (contenu validé réutilisé avec licence obligatoire), clients entreprises, sessions (modalité, dates,
  capacité, tarif approuvé, réservation client, formateur), inscriptions (public ou salariés), résultats de
  module (append-only, avec preuve, jamais par l'apprenant), avis, parcours de microcertifications,
  demandes de reconnaissance des acquis.
- Règles : publication par une autre personne que l'auteur ; modules figés après publication ; session close,
  complète ou réservée refusée ; conclusion seulement quand chaque module a un résultat (dernier résultat
  retenu) ; attestation et badge par le registre unique (ADR-0014), jamais de diplôme d'État ; parcours :
  toutes les formations réussies ; reconnaissance des acquis décidée et motivée par une autre personne, sans
  aucun effet automatique ; rapport de participation et de satisfaction exportable.
- Droits : `short.read`, `short.manage`, `short.approve`, `short.train`, `short.clients`, `short.rpl` ; rôles
  « Responsable des formations courtes » et « Formateur ».
- Écrans : `/formations-courtes` (catalogue public, inscription), `/formations-courtes/mes`, `/administration/formations-courtes`.
