# Lot 021 — Examens nationaux externes (suivi documentaire)

Relecture du 25 novembre 2026 : TDR module EXN (REQ-EXN-001 à 010 ; processus « information → dépôt
justificatif → contrôle → archivage » ; exceptions : fausse réussite, faux diplôme, confusion avec examen
interne), CLAUDE.md §1 (aucun diplôme national fabriqué, aucune organisation d'examen national),
MATRICE_ACCES (déposant ≠ vérificateur).

## Fiche

- Entités : information (`external_exam` : intitulé, autorité organisatrice, session, lien officiel HTTPS,
  brouillon → publiée → archivée), déclaration volontaire (`external_participation`), pièce officielle
  (`external_evidence` : type, autorité émettrice, référence, mention portée sur le document, fichier et
  empreinte ; contenu jamais réécrit), vérification (`external_verification`, append-only : étape, méthode,
  constat motivé, preuve éventuelle), historique (`external_event`, append-only).
- Règles : aucune table ne contient de note ni de résultat ; l'état affiché est celui de la vérification
  d'un document délivré par l'autorité nommée ; sans pièce vérifiée : « Non communiqué » ; vérification
  par une autre personne que le déposant (déclencheur) ; « autre » méthode positive exige une preuve ;
  vérification close définitive (nouveau dépôt sinon) ; preuves de vérification réservées à l'équipe.
- Droits : `exn.read`, `exn.manage`, `exn.verify` ; le déclarant n'accède qu'à ses déclarations et pièces.
- Écrans : `/examens-nationaux` (public, autorité organisatrice affichée, distinction avec les évaluations
  internes), `/examens-nationaux/suivi` (déclaration, dépôt, état, historique), `/administration/examens-nationaux`.
