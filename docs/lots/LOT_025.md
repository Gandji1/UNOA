# Lot 025 — Mémoires et soutenances

Relecture du 25 novembre 2026 : TDR module MEM (REQ-MEM-001 à 011 ; processus sujet → validation → encadrement →
rapport → jury → dépôt final ; exceptions : soutenance sans jury, mémoire plagié, fuite de contenu confidentiel),
lots 014 (inscriptions pédagogiques), 020 (notes : MEM-011), 008 (classes virtuelles, lien de soutenance).

## Fiche

- Entités (socle partagé avec le doctorat) : règlement des soutenances par portée et niveau (jury minimal,
  rapporteurs, membre extérieur, seuil de similarité, embargo maximal, délai de convocation), sujets, projets
  (protocole, confidentialité, unité de crédits), encadrement (directeur, codirecteur, qualification), jalons,
  versions PDF successives (append-only), commentaires, contrôles d'intégrité, soutenance (sur place, en ligne,
  hybride), membres et convocations, rapports, procès-verbal et signatures, dépôt définitif avec embargo.
- Règles : sujet et projet validés par une autre personne ; encadrement réservé aux personnes qualifiées
  (doctorat : habilitation à diriger) ; aucune version sans directeur en fonction ; suspicion au-delà du seuil
  ou examen humain : pas de soutenance sur une version suspecte ; jury conforme au règlement, président non
  encadrant, auteur exclu ; rapports favorables avant convocation ; délai de convocation ; quorum à la séance ;
  PV scellé et signé par les présents ; note de soutenance transmise comme note provisoire de l'unité (validée
  ensuite dans « Notes et jurys ») ; version corrigée exigée si des corrections sont demandées ; embargo dans
  la limite du règlement ; travail confidentiel jamais publié ni lisible hors de son cercle.
- Écrans : `/memoires` (archive publique), `/memoires/mes`, `/memoires/projet`, `/administration/memoires`.
