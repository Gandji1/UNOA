# Lot 020 — Notes, crédits et jurys

Relecture du 25 novembre 2026 : TDR module GRD (REQ-GRD-001 à 015, processus « note proposée → modération →
jury → validation → publication → recours », écrans, exceptions : réévaluation tardive, compensation non
permise, jury sans quorum), PARAMETRAGE_REGIONAL (grading.*), MATRICE_ACCES (auteur ≠ validateur,
étudiant ≠ instructeur de sa contestation), lot 014 (inscriptions), lot 007 (unités, crédits, coefficients).

## Fiche

- Entités : règle de notation (ADR-0012), note (historique append-only : provisoire, validée, rectifiée),
  jury (cohorte, période, session, règle, quorum, date de publication), membres et présence, décision
  calculée (append-only, avenant = nouvelle décision qui « amende » la précédente), signatures du PV
  (empreinte SHA-256), crédits (un en vigueur par étudiant et unité, capitalisés, révoqués seulement par
  avenant), contestation, rectification, relevé scellé.
- Droits : `grd.read`, `grd.policy`, `grd.enter` (ou enseignant d'une offre du cours de l'unité),
  `grd.validate`, `grd.jury`, `grd.appeal` ; délibération, publication et avenants par le président du jury ;
  signature par les membres présents. Rôle « Gestionnaire des notes et jurys ».
- Règles : validation par une autre personne que l'auteur (déclencheur) ; aucune délibération sur des notes
  provisoires ; quorum ; décisions calculées par le moteur (moyenne pondérée, arrondi documenté,
  compensation seulement si la règle l'autorise et au-dessus du plancher, seconde session « meilleure note »
  ou « remplace », absence justifiée → seconde session, injustifiée → zéro) ; note modifiée après
  délibération refusée hors avenant (U0409) ; publication après signature de tous les présents, visible
  à la date prévue ; contestation dans le délai de la règle ; relevé construit sur les seuls résultats publiés.
- Contrôles (GRD-014) : crédits au-delà de la formation, crédit sans unité validée, PV publié non signé,
  note modifiée après délibération sans avenant, seconde session sans première, décision différente du recalcul.

## Livré

Migration 0022, domaine `@unoa/domain/grading`, module `lib/grades`, API `/api/v1/grd/*`, écrans
`/administration/notes` (règles, cohortes, jurys, contestations, contrôles), `/administration/notes/saisie`,
`/administration/notes/jury` (composition, délibération, PV téléchargeable, signatures, publication,
décisions, avenants), `/resultats` (étudiant : résultats, crédits, contestation, relevé).
