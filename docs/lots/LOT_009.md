# Lot 009 — Audit, restructuration et sites multi-établissements

Relecture du 20 novembre 2026 : §1.3 (zéro contenu en dur), §3.2 (portails),
§4 (portées), §16.2 et 16.3 (arborescence, couches), §18, §21, module CMS
(001, 008, 009), CORE-001 et ADR 0001 à 0005. Revue du code des lots 001 à 008.

## Constats de l'audit

| Gravité | Constat | Exigence | Traitement |
|---|---|---|---|
| Haute | Nom, devise, accroche, pied de page et bouton de connexion écrits dans le code | §1.3, CMS-001, EXT-002 | Site public configurable par établissement ; aucun texte institutionnel dans le code |
| Haute | Catalogue et organigramme publics agrégeant tous les établissements | §4.1, TEN-007, CMS-002 | Résolution du site par nom d'hôte et filtrage des données publiques dans sa portée |
| Moyenne | Outils génériques rangés dans `lib/config`, `lib/studio` sans rôle clair, fichiers de 700 à 930 lignes | §16.3, CORE-001 | Noyau `lib/shared` (validation) et `lib/server` (transactions, audit, HTTP), modules découpés par responsabilité |
| Moyenne | Routes territoires et paramètres réimplémentant la chaîne HTTP | §16.5 | Même pipeline pour toutes les routes de studio |
| Moyenne | Recette HTTP dans un fichier `iam.test.mjs`, tests de paquets à la racine | §16.2 | `apps/web/test/recette.test.mjs` + `fixtures/`, tests dans chaque paquet, `tests/e2e/` |
| Basse | Valeur par défaut `territory` sur la nature des types de portée | TEN-001 | Nature explicite obligatoire |
| Basse | Pas d'index d'audit par acteur | IAM-011 | Index ajouté |
| Basse | Fiches de lots à la racine de `docs/` | §21 | `docs/lots/`, carte `docs/ARCHITECTURE.md` |

## Modèle (migration 0009)

`site` (portée locataire : plateforme, territoire ou établissement), `site_host`
(noms d'hôte), `site_text` (textes publiés par langue : nom, accroche, accueil,
présentation, contacts, mentions légales, confidentialité, illustration). Les
fonctions publiques prennent le site en paramètre et ne renvoient que les
objets de sa portée.

## Droits

`site.read`, `site.write`, `site.publish` sur la portée du site. La publication
est faite par une autre personne que le dernier rédacteur.

## Tests

Deux sites sur deux noms d'hôte desservant deux établissements : chacun ne voit
que son catalogue et son organigramme ; hôte inconnu sans site ; site non publié
invisible ; auto-publication refusée ; textes par langue ; mentions légales par
site. Non-régression des lots 001 à 008.
