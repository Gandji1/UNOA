# Démarrage du socle

Références : sections 2, 4, 16, 18 et 23 des TdR. REQ-CORE-001, 005, 013 et REQ-CFG-003, 007.
Premier incrément : workspace TypeScript, accueil institutionnel, sondes HTTP du processus web et résolution pure d’un paramètre daté par portée.
La lecture d’un paramètre reçoit une chaîne de portées préalablement autorisée, une clé et un instant UTC. Les règles publiées sont seules candidates. La correspondance la plus spécifique prime, puis la date et la version. Aucun accès institutionnel en écriture dans ce lot.
Recette : héritage, isolement de deux territoires fictifs, publication future, brouillon, repli, compilation, réponse HTTP des sondes et absence de données de démonstration sur le nouvel accueil.
Retour arrière : redéployer la version Vercel précédente. Aucune migration de données dans ce lot.
