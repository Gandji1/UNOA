Le prototype est une référence visuelle. Garder la navigation horizontale, le bleu foncé et une interface d’étude sobre. Utiliser un orange chaud modéré et opaque. Préserver les contrastes de lecture.
Distinguer dans les rapports le code testé, les exigences vérifiées, les simulations et les déploiements confirmés.
